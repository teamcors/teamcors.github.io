### 💬 가장 긴 증가하는 부분 수열
- 플랫폼: 백준 [[문제보기]](https://noj.am/11053)
- 문제 번호: 11053
- 풀이 시간: 45분

#### 메모
- `memo` 정의: `series[i]`를 시작으로 하는 증가수열의 최대 길이
    - 처음에 매개변수로 length를 증가시키면서 재귀했는데 이러면 memo의 정의에 맞게 캐싱할 수 없음
    - 그래서 depth가 깊은 순으로 카운트를 올려가면서 return 할때마다 카운트 올라가도록 다시 짬 --> AC

- `dp()` 내부에서 애초에 `i: [0, n)` 범위로 순회하는데 base case를 <= n 으로 설정하는 실수를 함
- `for j in range(i, n):` --> 이거 `i+1` 부터 순회해야하는ㄷ (코드 안고치고 푸시함;)

### 💬 포도주 시식
- 플랫폼: 백준 [[문제보기]](https://noj.am/2156)
- 문제 번호: 2156
- 풀이 시간: 26분 15초

#### 메모
- 1트에 안풀려서 DP 설계 첨부터 다시 함
- `dp(i)` --> `i`번째 포도주에 대하여
    - `i`를 선택 안하고 다음꺼 선택
    - `i`를 선택하고 다음꺼 선택 (단, 이전에 연속선택 안했을때 (=`prev_status`가 `False`일 때))
    - `i`를 선택하고 한 칸 건너뛰어서 선택 (단, 이전에 연속선택 안했을때 (=`prev_status`가 `False`일 때))
    - `i`를 선택 안하고 한 칸 건너뛰는건 당연히 `i` 선택한게 더 나으므로 호출하지 않음
- 따라서 총 3가지 경우에 대해 재귀 호출했고 메모이제이션 함
    <li><b><span style="font-size:32px">setrecursionlimit 좀 그만 까먹어라</span></b></li>
